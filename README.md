# 💠 تدفّق — مركز إدارة المال الشخصي

تطبيق ويب عربي كامل (RTL) لإدارة المال الشخصي، مبني من الصفر **بدون أي مكتبات خارجية** — HTML + CSS + JavaScript خالص. يعمل كتطبيق PWA قابل للتثبيت ودون اتصال.

## ✨ المزايا

| الصفحة | ماذا تفعل |
|---|---|
| 📊 لوحة التحكم | رصيد حي، دخل/مصروف/معدل توفير بعدّادات متحركة، رسم تدفق نقدي خطي، دونات تفاعلية لتوزيع المصروفات (مرّر الماوس!) |
| 🧾 المعاملات | إضافة/تعديل/حذف مع **تراجع فوري**، بحث فوري، فلاتر (نوع، شهر، تصنيف)، ملخصات محسوبة، ومدير **المعاملات المتكررة** |
| 🎛️ الميزانيات | سقف شهري لكل تصنيف، أشرطة تقدّم، تحذيرات تجاوز، توقّع ذكي لنهاية الشهر |
| 🎯 الأهداف | حلقات تقدّم، إيداعات، عدّ تنازلي، كونفيتي احتفالي، **محاكاة «ماذا لو»**، و**تحديات ادخار** |
| 📈 التقارير | أعمدة دخل×مصروف، **خريطة حرارية يومية** للشهر، وتحليل ذكي يولّد نصائح تلقائيًا |
| ⚙️ الإعدادات | ثيم داكن/فاتح، 8 عملات، تصدير/استيراد JSON، وزر تثبيت التطبيق |

## 🆕 إصدار 2.0
- 🔁 **معاملات متكررة** — الراتب والإيجار والاشتراكات تُسجَّل تلقائيًا كل شهر (مع التقاط أي شهر فاتك)، وإيقاف/تفعيل مؤقت، وشارة 🔁 على المعاملات المولّدة
- 📲 **PWA كامل** — Service Worker + Manifest + أيقونات مولّدة برمجيًا: يُثبَّت كتطبيق ويعمل دون إنترنت
- 🗓️ **خريطة حرارية** — تقويم شهري يلوّن أيامك حسب شدة الصرف (أخضر ← أصفر ← أحمر) مع إحصاءات أعلى يوم وأيام بلا صرف
- 🧪 **محاكاة ماذا لو** — حرّك شريط الادخار الشهري وشاهد تاريخ الوصول لهدفك فورًا
- ↩️ **تراجع عن الحذف** — زر «تراجع» داخل الإشعار بدل الحذف النهائي
- ⌘ **لوحة أوامر Ctrl+K** — أوامر سريعة + بحث فوري في معاملاتك بأسهم لوحة المفاتيح
- 🏆 **تحديات ادخار** — تحدي 52 أسبوعًا (52 خانة تفاعلية) وتحدي «أيام بلا صرف» مع سلسلة أيام متتالية 🔥

## 🎨 لمسات الإبداع
- كل الرسوم البيانية **مرسومة يدويًا على Canvas** بأنيميشن كشف تدريجي
- خلفية جزيئات حية + كرات ضوء + توهج يتبع المؤشر + شاشة بداية بشعار يُرسم ذاتيًا
- متجاوب بالكامل: شريط سفلي على الجوال، وأيقونات PWA بأحجام 192/512 (maskable)

## 🚀 التشغيل
افتح `index.html` مباشرة، أو شغّل خادمًا محليًا (مطلوب لتجربة التثبيت PWA):
```bash
npx serve tadafuq
```

## ⌨️ اختصارات
- `Ctrl + K` — لوحة الأوامر والبحث
- `↑ ↓` التنقل داخل اللوحة، `Enter` للتنفيذ
- `Esc` — إغلاق النوافذ
